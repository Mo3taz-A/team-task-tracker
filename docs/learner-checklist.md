# Learner Checklist

Use this checklist to confirm you completed the exercise like a professional GitHub contributor.

## Foundation

- [ ] I read `README.md`, `CONTRIBUTING.md`, and `SECURITY.md`
- [ ] I ran `npm install`
- [ ] I ran `npm start`
- [ ] I ran `npm test`
- [ ] I ran `npm run lint`
- [ ] I read the practice issue in `docs/issues/12-completed-task-filter.md`

## Collaboration

- [ ] I created a branch from `main`
- [ ] My branch name describes the work
- [ ] I kept my change focused on the assigned issue
- [ ] I wrote a clear commit message
- [ ] I opened a pull request with a summary, related issue, and testing notes

## Quality

- [ ] I added or updated tests for the new behavior
- [ ] I checked edge cases, not just the happy path
- [ ] My pull request passed GitHub Actions
- [ ] I updated documentation if the behavior changed

## Security and responsibility

- [ ] I did not commit secrets or sensitive data
- [ ] I reviewed any Copilot suggestions before accepting them
- [ ] I can explain why the final code is correct

## Professional GitHub developer

- [ ] I responded professionally to review comments
- [ ] I understood and resolved any CI or merge issues
- [ ] I waited for approval before merge
- [ ] I can explain why each GitHub step matters, not just which button to press

## Completion criteria

You are done when:

- the feature works
- tests cover the new behavior
- lint passes
- the pull request is clear and reviewable
- you understand the workflow you just used
